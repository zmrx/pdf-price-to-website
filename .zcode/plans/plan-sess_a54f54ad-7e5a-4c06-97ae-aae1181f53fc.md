# Прайс-лист «ТИХИЕ СТЕНЫ» как сайт

## Context

Проект `pdf-to-website` — свежий scaffold Vue 3 + TypeScript + Vite + Vue Router (зависимости установлены). Задача: превратить PDF `public/Прайс лист для  Партнеров дилеров ТС сентябрь 2026.pdf` в сайт:
- отдельная страница под каждую таблицу;
- главная со ссылками на таблицы по названиям;
- все данные вынести в JS-массив, HTML-таблицы строить из него.

**Источник данных — страница 1 PDF** (оформленный финальный прайс: 5 таблиц, полные данные). Страница 2 — черновой дубль (нет таблиц «Звукоизоляция» и «Образцы», часть цен указана за комплект) — не используется.

Таблицы со стр. 1:
1. **Ткани и акустические материалы** (7 колонок; группы: основная, «Под заказ — цена по согласованию», «Импортный акустический текстиль»; 13 строк)
2. **Звукоизоляция** (группы-заголовки: ТС ПРО / АРГАПАЛ / Комплектный поддон, у каждой 1–2 строки цен; сноска о комплекте)
3. **Профили · цена за м.п.** (группы: чёрный / неокрашенный / белый / другое; 24 строки)
4. **Комплектующие** (группы: Закладные, Инструмент/расходник, Каталоги/стенды, Уголки и соединители + примечание о цене за комплект 10 шт., Чистящие средства, Рассеиватели; 27 строк)
5. **Образцы** (2 строки)

Колонки «Габариты/Объём/Вес пачки» в таблицах 3 и 4 в PDF пустые — на сайте опускаю (в таблице 2 данные есть и включаются).

## Реализация

### 1. `src/data/priceList.ts` — данные в виде JS-массива (новый файл)

```ts
export interface PriceCell { text: string; colspan?: number; rowspan?: number }
export interface PriceRow { cells: (string | PriceCell)[] }   // string — обычная ячейка
export interface PriceGroup { title?: string; note?: string; rows: PriceRow[] }
export interface PriceTable {
  id: string        // 'fabrics' | 'insulation' | 'profiles' | 'components' | 'samples'
  title: string     // напр. '1. Ткани и акустические материалы'
  columns: string[] // заголовки колонок
  groups: PriceGroup[]
  footnote?: string
}
export const priceListMeta = { brand: 'ТИХИЕ СТЕНЫ', subtitle: '…действует с 01.02.2026', warning: { text: '…', url: 'https://tkansklad.ru/' } }
export const priceList: PriceTable[] = [ /* все ~70 строк из стр. 1 PDF */ ]
```

Особенности данных:
- «Цена по согласованию» — ячейка с `colspan: 3` (РРЦ + Оф. дилер + Партнёр);
- в «Звукоизоляции» Габариты/Объём/Вес — ячейки с `rowspan: 2` (у ТС ПРО общие на 2 строки цен);
- длинные заголовки колонок («Партнёр, общая закупка ТОЛЬКО ПРОФИЛЯ от 700 000 ₽» и т.п.) — как в PDF.

### 2. `src/components/PriceTable.vue` — рендер таблицы из данных

Универсальный компонент: `thead` из `columns`, строки групп (`title` → полноширинная строка-заголовок `<th colspan>`, `note` → строка-примечание), строки данных с поддержкой `rowspan`/`colspan`, `footnote` под таблицей. Числовые колонки выравниваются вправо.

### 3. `src/pages/HomeView.vue` — главная

Шапка (бренд, подзаголовок, предупреждение со ссылкой на tkansklad.ru) + список ссылок `<RouterLink>` на таблицы по их названиям.

### 4. `src/pages/TableView.vue` — страница таблицы

Читает `route.params.id`, находит таблицу в `priceList`, показывает: ссылка «← Все таблицы», название, `PriceTable`, сноску. Неизвестный id — сообщение и ссылка на главную.

### 5. `src/router/index.ts` — маршруты

```
/            → HomeView
/table/:id   → TableView
```

### 6. `src/App.vue` — каркас

Верхняя панель (бренд-ссылка на главную) + `<RouterView />` + подвал («Цены указаны в рублях. РРЦ — рекомендованная розничная цена…»).

### 7. `src/style.css` — оформление

Чистый CSS без библиотек: тёмная акцентная шапка (как в PDF), таблицы с бордюрами и «зеброй», полноширинные строки групп с заливкой, sticky-заголовок таблицы, обёртка с горизонтальным скроллом для мобильных, цены моноширинным выравниванием вправо.

### 8. Прочее

- `index.html`: `lang="ru"`, title «ТИХИЕ СТЕНЫ — Прайс-лист».
- Удалить неиспользуемый код шаблона: `src/components/HelloWorld.vue`, `src/assets/hero.png`, `src/assets/vite.svg`, `src/assets/vue.svg`, `public/icons.svg` (favicon.svg оставить).
- Перед кодом загружаю скиллы `my-vue3` и `my-code-patterns` (стандарты Vue 3 и кода).

## Верификация

1. `npm run dev` — проверить главную (5 ссылок) и каждую страницу `/table/fabrics|insulation|profiles|components|samples`.
2. Сверка данных с PDF: текстовый слой стр. 1 уже извлечён полностью — построчная проверка массива против него (названия, цены, группы).
3. `npm run build` — прогон `vue-tsc` (типы) и сборка без ошибок.
4. Визуальная проверка в браузере: объединённые ячейки (rowspan в «Звукоизоляции», colspan «Цена по согласованию»), мобильная прокрутка таблиц.
